# Offline rehearsal fixtures

These fixtures are synthetic and contain no account, cookie, fingerprint, or captured challenge data. They exercise one deterministic Level 1 problem, one Level 2 catalog lookup, and compilation of a committed Level 3 candidate.

Use `npm run rehearse:v3` from the repository root. Pass `--run-dir` and `--level2-catalog` only when rehearsing against private, ignored local artifacts.
